Cardápio Digital com Chatbot para WhatsApp
Um sistema integrado de cardápio digital conectado a um chatbot automatizado para atendimento via WhatsApp, ideal para restaurantes, lanchonetes e deliverys que desejam otimizar o fluxo de pedidos e o relacionamento com o cliente.

Funcionalidades Principais
Cardápio Interativo: Interface digital leve e responsiva para que os clientes visualizem produtos, categorias, descrições e preços diretamente pelo celular.

Automação de Pedidos (Chatbot): Direcionamento e estruturação automática dos pedidos recebidos via WhatsApp, agilizando o atendimento e reduzindo erros humanos.

Fácil Atualização: Estrutura flexível para gerenciar itens, adicionar novidades ou alterar valores de forma simples.

Tecnologias Utilizadas
Frontend / Interface: HTML5 / CSS / JavaScript

Estruturação de Dados: JSON

Canal de Atendimento: WhatsApp

Estrutura do Repositório
Plaintext
├── HTML.html           # Interface principal do cardápio digital
├── funil_K5kdeG.json   # Fluxo/configuração do chatbot para automação
└── README.md           # Documentação do projeto
Como Usar
Configuração do Cardápio: Edite o arquivo HTML.html para personalizar as categorias, produtos, preços e identidade visual do seu estabelecimento.

Importação do Chatbot: Importe o arquivo funil_K5kdeG.json na ferramenta de automação de WhatsApp de sua preferência para configurar os fluxos de conversa e atendimento.

Publicação: Hospede o cardápio em um servidor web (como GitHub Pages, Vercel ou Netlify) e utilize o link gerado junto ao seu número comercial do WhatsApp.
